### （四）实现逻辑语句的IR生成

1.条件语句：对于条件语句，其基本实现方法通过是创建多个基本块来对应不同的执行路径（then、else、merge），通过条件跳转指令来控制程序流程。特别地，需要考虑else块不存在的情况，以及因为then块和else块内存在return等跳转指令，而不需要跳转到merge块的情况。在实现中，对这些情形进行了处理。另外需要注意的一点是插入点的指定，在编写指令时，需要将插入点设置到对应的基本块中，最后也要将插入点调整到merge块，以便后续代码的生成。
```cpp
void
EmitIR::operator()(IfStmt* obj)
{
  auto& irb = *mCurIrb;
  // 创建基本块
  llvm::BasicBlock *thenBb = nullptr, *elseBb = nullptr, *mergeBb = nullptr;
  thenBb = llvm::BasicBlock::Create(mCtx, "if.then", mCurFunc);
  if (obj->else_) elseBb = llvm::BasicBlock::Create(mCtx, "if.else", mCurFunc);
  mergeBb = llvm::BasicBlock::Create(mCtx, "if.end", mCurFunc);
  // 直接在原基本块开始判断if的条件
  auto condVal = self(obj->cond);
  if (condVal->getType()->isIntegerTy(32))
    condVal = irb.CreateICmpNE(condVal, irb.getInt32(0));
  // 根据条件值跳转到不同的基本块
  irb.CreateCondBr(condVal, thenBb, elseBb ? elseBb : mergeBb);
  // 处理then部分
  irb.SetInsertPoint(thenBb);
  self(obj->then);
  // 如果then部分没有以跳转语句结束，则添加跳转到mergeBb的指令
  if (!irb.GetInsertBlock()->getTerminator())
    irb.CreateBr(mergeBb);
  // 如果有else部分，则处理else部分
  if (elseBb) {
    irb.SetInsertPoint(elseBb);
    self(obj->else_);
    // 如果else部分没有以跳转语句结束，则添加跳转到mergeBb的指令
    if (!irb.GetInsertBlock()->getTerminator())
      irb.CreateBr(mergeBb);
  }
  // 调整插入点到mergeBb，方便后续的代码生成
  mCurIrb->SetInsertPoint(mergeBb);
}
```

### （五）实现短路求值的IR生成


1.实现And短路求值，因为涉及到不同的求值路径，所以也需要设计多个基本块。对于And表达式，首先判断左侧值，如果左侧值为假，则直接跳转到结果为假的基本块；如果左侧值为真，则跳转到判断右侧值的基本块。最后在合并结果的基本块中使用`phi`指令来合并不同路径的结果。需要注意的是，在处理右侧值的基本块时，内层也可能存在短路求值，因此需要在`phi`的`addIncoming`方法中输入的基本块应该是最终得到右侧值的基本块，而不是`trueBb`，这一点困扰了我比较长时间。Or的短路求值实现与And类似，此处不再赘述。
```cpp
  case BinaryExpr::Op::kAnd: {
    // 短路求值基本块
    auto trueBb = llvm::BasicBlock::Create(mCtx, "and.true", mCurFunc);
    auto endBb = llvm::BasicBlock::Create(mCtx, "and.end", mCurFunc);
    // 在原基本块判断左侧值
    lftVal = self(obj->lft);
    if (!lftVal->getType()->isIntegerTy(1))
      lftVal = irb.CreateICmpNE(lftVal, llvm::ConstantInt::get(lftVal->getType(), 0));
    irb.CreateCondBr(lftVal, trueBb, endBb);
    auto predBb = irb.GetInsertBlock();
    // 在trueBb判断右侧值
    irb.SetInsertPoint(trueBb);
    rhtVal = self(obj->rht);
    if (!rhtVal->getType()->isIntegerTy(1))
      rhtVal = irb.CreateICmpNE(rhtVal, llvm::ConstantInt::get(rhtVal->getType(), 0));
    irb.CreateBr(endBb);
    // 由于内层可能也有短路求值，需要获取右侧值的基本块以便后续phi指令使用
    auto rhtBb = irb.GetInsertBlock();
    // 在endBb合并结果
    irb.SetInsertPoint(endBb);
    // phi指令
    auto phi = irb.CreatePHI(llvm::Type::getInt1Ty(mCtx), 2, "merge");
    phi->addIncoming(irb.getInt1(0), predBb);
    phi->addIncoming(rhtVal, rhtBb);
    return phi;
  }
```

### （六）修复问题

1.二元运算执行顺序问题：这基本是一个粗心导致的问题，二元表达式的左右子表达式的生成顺序应该是从左向右，但之前的实现中直接把子表达式的生成放在了`CreateSub`等指令的参数中，导致生成顺序不确定，这就造成了`062_side_effect.sysu.c`测试点的失败，因为这个测试点中存在自增等具有副作用的表达式，如果生成顺序不正确，就会导致结果错误。我是在AI工具的提示下才意识到这个问题的，其实最早的写法就是正确的，但后来为了简化代码，直接把子表达式的生成放在了指令参数中。
```cpp
// 062_side_effect.sysu.c中的表达式
if (inc_a() < 14 || inc_a() && inc_a() - inc_a() + 1)
```
- 对此问题的修复方法是以确定顺序的方式生成左右子表达式的值，如下：
```cpp
    case BinaryExpr::Op::kSub: {    // 修改前
      return irb.CreateSub(self(obj->lft), self(obj->rht));
    }
    case BinaryExpr::Op::kSub: {    //修改后
      lftVal = self(obj->lft);
      rhtVal = self(obj->rht);
      return irb.CreateSub(lftVal, rhtVal);
    }
```
