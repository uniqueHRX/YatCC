### （二）实现token词法规则定义

在`lex.l`中进行词法规则定义的形式如下：

```
","                      { ADDCOL(); COME(COMMA); }
"."                      { ADDCOL(); COME(PERIOD); }

"char"                   { ADDCOL(); COME(CHAR); }
"short"                  { ADDCOL(); COME(SHORT); }

0[0-7]*{IS}?             { ADDCOL(); COME(CONSTANT); }
[1-9]{D}*{IS}?           { ADDCOL(); COME(CONSTANT); }
```
语法分析器自上而下匹配输入文本，按照最长匹配原则进行匹配。对于每个匹配的规则，执行相应的动作，如更新列号（`ADDCOL()`）和返回token（`COME(id)`）。

首先运行一次测试，观察结果，与标准输出对比发现部分测试中存在被遗漏的token，导致测试不通过。

尝试手写部分词法规则定义，来补全个别缺失的token，例如"-"号：
```
"-"         { ADDCOL(); COME(MINUS); }
```
同时在lex.hpp中添加对应的token枚举：
```hpp
enum Id {
    ...
    MINUS,
    ...
};
```
并在lex.cpp中添加token名映射表，位置和枚举Id中的位置对应：
```cpp
static const char* kTokenNames[] = {
    ...
    "minus",
    ...
};
```

并运行测试，观察测试结果是否反映了规则定义的正确性。注意到关于sub的一项测例在修改完成后通过了，验证了我对于这一部分实现方法的理解：


### （三）处理位置标志信息

接下来注意到尽管token的类型和文本值都正确了，但位置标志信息和文件路径不正确，导致测试无法得到满分。

于是利用AI辅助编写space()函数来处理位置标志信息，代码如下：
```cpp
void space(char c)
{
  if (c == '\n') {
    g.mLine++;
    g.mColumn = 1;
    g.mStartOfLine = true;
    g.mLeadingSpace = false;
  } else if (c == ' ' || c == '\t') {
    g.mColumn++;
    g.mLeadingSpace = true;
  }
}
```
该函数根据输入的字符类型更新行号、列号以及位置标志。对于换行符，行号增加，列号重置为1，并设置`startOfLine`为true，`leadingSpace`为false。对于空格和制表符，列号增加，并设置`leadingSpace`为true。

同时考虑到预处理行也需要进行处理，并从中获取文件路径和行号信息，所以利用AI辅助编写extract_preprocessed_info()函数来处理预处理行，代码如下：
```cpp
void extract_preprocessed_info(const char* line)
{
  // line format: # 123 "filename"
  // we need to extract line number and filename
  // skip '#'
  const char* p = line + 1;
  while (*p && (*p == ' ' || *p == '\t')) p++;
  // read line number
  int lineNum = 0;
  while (*p >= '0' && *p <= '9') {
    lineNum = lineNum * 10 + (*p - '0');
    p++;
  }
  // skip spaces
  while (*p && (*p == ' ' || *p == '\t')) p++;
  // expect double quote
  if (*p != '"') return;
  p++;
  const char* filenameStart = p;
  while (*p && *p != '"') p++;
  if (*p != '"') return;
  std::string filename(filenameStart, p - filenameStart);
  // update global state
  g.mFile = filename;
  // line number should be decremented by 1 because the newline after this line will increment it
  g.mLine = lineNum - 1;
  g.mColumn = 1;
  g.mStartOfLine = true;
  g.mLeadingSpace = false;
}
```
该函数根据预处理行结构对预处理行进行解析，提取文件路径和行号信息，并更新全局状态，即文件路径、行号、列号以及位置标志。

然后将这些辅助函数定义到`lex.hpp`中，并在`lex.l`中调用这些函数来处理相应的输入行和空白字符。

同时在AI辅助下还注意到需要在`main.cpp`中修改`print_token()`函数来输出位置标志信息，增补的代码如下：
```cpp
  ...
  if (!lex::g.mStartOfLine && !lex::g.mLeadingSpace)
    outFile << "\t";
  // compute start column (1-based)
  int startCol = lex::g.mColumn - static_cast<int>(lex::g.mText.length());
  // ensure not less than 1 (should not happen)
  if (startCol < 1) startCol = 1;
  outFile << "\tLoc=<" << lex::g.mFile << ":" << lex::g.mLine << ":" << startCol << ">\n";
  ...
```

最后修正了一些小问题，例如从come()函数中去掉给行号赋值的代码，因为行号的更新应该在处理空白字符时进行，而不是在返回token时进行：
```cpp
g.mLine = yylineno;  //删除的代码
```
